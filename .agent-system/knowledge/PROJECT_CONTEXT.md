# Project Context — Get Idiomas AI Writing System

## 1. Executive Summary

**Get Idiomas** is an English language academy preparing students for official Cambridge Assessment English examinations (B1 Preliminary, B2 First, C1 Advanced, and C2 Proficiency). Writing evaluation is one of the most resource-intensive aspects of language teaching, demanding meticulous annotation of grammar, vocabulary, coherence, register, and rubric criteria.

The project builds an end-to-end platform for writing submission, automated multimodal AI evaluation, teacher supervision/calibration canvas, and a commercial license/membership engine.

## 2. Core Strategic Philosophy: AI-First

The project follows an **AI-First strategy**:
1. **Engine Before UI**: The LangGraph AI evaluation engine and backend API are developed and benchmarked first, ensuring pedagogical reliability before investing in student/teacher graphical frontends.
2. **Benchmark Gate**: Before any UI release, the AI pipeline must be validated against a benchmark of 50-80 real academy essays, attaining:
   - Mean Absolute Error (MAE) $\le 0.5$ bands.
   - Exact band match accuracy $\ge 80\%$.
3. **Commercial Layer Last**: The memberships, subscriptions, and student licensing modules are integrated in the final phase once the core academic and evaluation workflows are fully validated.

## 3. Pedagogical Framework: Cambridge Assessment English

The system assesses student writings based on the 4 official Cambridge criteria:

1. **Content**: Focuses on task fulfillment, addressing all prompt bullet points, relevance, and target reader information.
2. **Communicative Achievement**: Focuses on genre conventions, appropriate register (formal/neutral/informal), tone, and communicative purpose.
3. **Organisation**: Evaluates logical paragraphing, coherence, text progression, linking words, and cohesive devices.
4. **Language**: Measures range and control of everyday vs. advanced vocabulary, grammatical structures, flexibility, and error severity.

### Band Scales & Equivalence
- **Raw Band Scale**: 0 to 5 in integer or half-band increments per criterion (Total: 0 to 20).
- **Internal 10-Point Grade**: Mapped via an internal institutional equivalence formula.
- **Trademark Neutrality**: Student-facing score displays use internal institutional nomenclature ("Calificación Institucional", "Bandas de Competencia"), avoiding trademark infringements with Cambridge University Press & Assessment.

## 4. Key User Roles

1. **Administrator (`admin`)**:
   - Manages institutional accounts, course setup, and license allocations.
   - Real-time audit log oversight and token consumption monitoring.
2. **Teacher (`teacher`)**:
   - Creates assignments, sets deadlines, and chooses rubric configurations.
   - Reviews AI pre-evaluations on an interactive canvas (Split View for OCR, bidirectional text annotator).
   - Calibrates rubric sliders, overrides error flags, edits feedback, and publishes official reviews.
3. **Student (`student`)**:
   - Completes assignments via the Virtual Writing Editor or uploads handwritten photos.
   - Accesses published grades, annotated errors, pedagogical feedback, and Band 5 exemplar models.
   - Participates in the "Second Version" rewrites to reinforce learning.

## 5. Main Functional Workflows

- **Dual Submission Formats**:
  - *Digital Submission*: Rich online editor with live word count, local autosave, and exam mode (blocking copy-paste when enabled).
  - *Handwritten Submission*: Multi-photo upload with literal OCR transcription and split-view verification.
- **Dual Evaluation System**:
  - `AIEvaluation`: Inmutable automated snapshot generated by LangGraph.
  - `TeacherReview`: Teacher-moderated, published evaluation shown to students.
- **Pedagogical Revision Loop (Second Version)**:
  - Students review teacher-published feedback and submit a second version addressing highlighted issues.
  - Teachers compare Version 1 vs Version 2 diffs to confirm skill progression.
- **Exemplar Model (Band 5) Visibility Control**:
  - Teachers configure whether the AI-generated Band 5 model is visible immediately upon grading or unlocked only after the student submits a second version rewrite.
