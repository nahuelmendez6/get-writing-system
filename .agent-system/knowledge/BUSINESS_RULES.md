# Business Rules — Get Idiomas AI Writing System

## 1. Cambridge Assessment Framework & Rubrics

### 1.1. Evaluation Criteria
Every writing is evaluated across 4 core criteria defined by Cambridge Assessment English:

1. **Content**:
   - Focuses on how well the candidate has fulfilled the task.
   - Evaluates whether all required prompt elements are addressed and relevant.
2. **Communicative Achievement**:
   - Focuses on genre appropriateness, target reader engagement, tone, and register (informal, neutral, formal).
3. **Organisation**:
   - Focuses on paragraph structure, logical coherence, cohesion, and usage of linking devices.
4. **Language**:
   - Focuses on lexical resource (vocabulary range and precision) and grammatical control (range, complexity, and accuracy of structures).

### 1.2. Band Scale (0 to 5)
- Each criterion receives a score from **0 to 5** (increments of 0.5 or 1.0 depending on stage).
- Total raw score range: **0 to 20 points**.
- **Band Descriptors**:
  - `Band 5`: Exemplary performance for target level; wide vocabulary, complex structures, flawless register.
  - `Band 3`: Satisfactory pass level; conveys message clearly, minor non-impeding errors.
  - `Band 1`: Below required level; severe inaccuracies, incomplete ideas, inappropriate register.
  - `Band 0`: Irrelevant response, completely illegible, or insufficient text to assess.

### 1.3. Institutional Grade Conversion (Scale 0 to 10)
- The raw score (0-20) is mapped to an internal decimal grade between **0.0 and 10.0**:
  $$\text{Grade} = \left(\frac{\text{Content} + \text{Comm. Achievement} + \text{Organisation} + \text{Language}}{20}\right) \times 10$$
- Institutional Pass Threshold: **6.0 / 10.0** (equivalent to Band 3 across all 4 criteria).
- **Trademark Policy**: All student-facing screens and exported PDFs must use neutral institutional terminology ("Calificación del Writing", "Nivel de Dominio") without using the registered trademark "Cambridge" as an official endorsement.

## 2. Evaluation Lifecycle & Immutability

```
[ AI Processing ] ──► [ AIEvaluation (Immutable) ]
                             │
                             ▼ (Initializes)
                      [ TeacherReview (Draft) ]
                             │
                             ▼ (Teacher Calibration)
                      [ TeacherReview (Approved) ]
                             │
                             ▼ (Final Publish)
                      [ TeacherReview (Published) ] ──► Visible to Student
```

1. **AIEvaluation Immutability**:
   - An `AIEvaluation` generated by the LangGraph engine is read-only and immutable.
   - If re-processing occurs (e.g. after prompt update or teacher request), a new `AIEvaluation` record with an incremented version number is created. Previous versions are archived.
2. **Teacher Review Moderation**:
   - The teacher uses the AI evaluation as a calibrated draft.
   - Teachers can accept, modify, or delete detected error markers, calibrate band sliders, and edit feedback notes.
3. **Visibility Gate**:
   - A student can **never** view an `AIEvaluation` directly or a `TeacherReview` in `DRAFT` or `APPROVED` state.
   - Results only become accessible to students once status transition to `PUBLISHED` occurs.

## 3. Handwritten Submissions & Literal OCR Policy

1. **Strict Literal Transcription**:
   - OCR transcription must strictly capture student writing verbatim, preserving all spelling mistakes, grammar errors, capitalizations, and punctuation flaws.
   - Automated language correction must **never** take place during the OCR transcription phase.
2. **Confidence Flagging & Split View**:
   - Words with recognition confidence below threshold ($< 80\%$) are tagged with visual markers.
   - Teachers have a mandatory Split View interface (photograph on left, transcribed text on right) to rectify OCR misreadings before publishing grades.

## 4. Exemplar Model (Band 5) Visibility Control

Assignments support configurable disclosure for the AI-generated Band 5 model essay:
- **Immediate Disclosure (`ALWAYS_VISIBLE`)**: The exemplar model is visible to the student as soon as the teacher publishes the review.
- **Conditional Disclosure (`AFTER_SECOND_VERSION`)**: The exemplar model is hidden until the student submits a "Second Version" rewrite incorporating the teacher's corrections.

## 5. Second Version (Rewrite) Flow

1. Students have the pedagogical option to submit a **Second Version** of an evaluated writing.
2. The second version is linked to the original submission (`parent_submission_id`).
3. The teacher interface displays a side-by-side diff comparison between Version 1 and Version 2, highlighting corrected errors and iterative improvement.

## 6. Word Count Boundaries & Warnings

- Each assignment specifies `min_words` and `max_words` (e.g., B2 First Essay: 140–190 words).
- Tolerance buffer: $\pm 10\%$.
- Submissions outside the tolerance threshold trigger an automatic "Length Penalty" alert in the Content evaluation criterion.

## 7. Memberships, Licenses & Quota Gating (Phase 7)

1. **Student License (`StudentLicense`)**:
   - Grants access to specific CEFR levels (e.g., B2 only, C1 only, or Full Access).
   - Tracks monthly quotas for digital and handwritten submissions.
   - Distinguishes between automated AI-only pre-grades and teacher human review credits.
2. **Access Control Enforcement**:
   - If a student's license is expired, suspended, or out of credits, submission endpoints must reject requests with HTTP 402/403 and informative error codes.
