# API Documentation Skill

## Purpose
Ensures RESTful API routes and schemas are clearly documented for frontend engineers and external integrations.

## Guidelines
1. **Endpoint Docstrings**: Include concise summaries, path/query parameter explanations, and possible error status codes.
2. **Schema Examples**: Provide meaningful Pydantic schema examples in field definitions.
3. **OpenAPI Export**: Verify that the generated OpenAPI specification remains valid and error-free.
