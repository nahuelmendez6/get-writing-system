# Changelog Management Skill

## Purpose
Maintains a clean, chronological history of all updates made to the platform.

## Guidelines
1. **Categorization**: Use standard Keep a Changelog categories (`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`).
2. **Atomic Entries**: Ensure each task delivers concise bullet points linking to task IDs and commit scopes.
3. **Traceability**: Mention user-facing impacts clearly for non-technical stakeholders.
