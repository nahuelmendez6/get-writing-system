# Technical Documentation Skill

## Purpose
Enables the Documenter to write clear, structured, and developer-friendly documentation for system modules.

## Guidelines
1. **GitHub Markdown Standards**: Use proper alerts (`> [!NOTE]`, `> [!WARNING]`), tables, and code formatting.
2. **Setup Instructions**: Keep onboarding and deployment steps reproducible and unambiguous.
3. **Traceability**: Reference corresponding backlog task codes and requirements in all documentation sections.
