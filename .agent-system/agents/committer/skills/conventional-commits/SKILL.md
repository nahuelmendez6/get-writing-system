# Conventional Commits Skill

## Purpose
Guarantees consistent, structured commit messages that automate changelog generation and semantic versioning.

## Guidelines
1. **Header Format**: `<type>(<scope>): <description>`
   - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`.
   - Scopes: `auth`, `users`, `courses`, `assignments`, `submissions`, `evaluations`, `ocr`, `rubrics`, `licenses`.
2. **Body**: Provide a concise paragraph explaining the motivation for the change.
3. **Footer**: Include task reference: `Task-Ref: TASK-1.1`.
