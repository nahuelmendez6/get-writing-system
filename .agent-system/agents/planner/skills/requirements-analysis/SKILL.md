# Requirements Analysis Skill

## Purpose
Translates pedagogical and business requirements into concrete technical specifications.

## Guidelines
1. **Traceability Mapping**:
   - Every planned task must trace back to a specific requirement code (e.g., `RF-01`, `RF-08`) in `requirements`.
2. **Ambiguity Elimination**:
   - If an edge case is unspecified (e.g., handling missing word counts, grading ties), resolve it using `knowledge/BUSINESS_RULES.md` or flag for human clarification.
3. **Cambridge Framework Compliance**:
   - Ensure requirements align with the 4 Cambridge criteria (Content, Communicative Achievement, Organisation, Language) and band scale (0-5).
