# Frontend Development Skill

## Purpose
Enables the Implementer to build and integrate frontend pages, connecting UI components to backend endpoints.

## Guidelines
1. **Prototype Alignment**: Reuse design patterns, layouts, and components from `/prototipe/src/`.
2. **Strict Typing**: Enforce strict TypeScript types matching the backend Pydantic API response schemas.
3. **Interactive Features**: Implement autosave, interactive text annotators, and Cambridge rubric sliders.
4. **Production Hygiene**: Ensure `DevRoleSwitcher` and demo mocks are excluded from production builds.
