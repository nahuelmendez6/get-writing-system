# Definition of Done

A task is considered complete when:

## Requirements

- All acceptance criteria are satisfied.
- All related requirements are addressed.
- No unapproved scope changes exist.

## Implementation

- Code follows project architecture.
- No duplicated functionality is introduced.
- Pydantic schemas are properly defined.
- TypeScript types are correct.
- Database migrations are included when necessary.
- Error handling is implemented.
- Authorization rules are respected.

## Testing

- Unit tests pass.
- Integration tests pass when applicable.
- Existing tests remain green.
- No critical regression is introduced.

## Documentation

- API documentation is updated.
- Relevant docstrings are updated.
- ADRs are created when necessary.
- README is updated when execution or configuration changes.

## Version Control

- Changes are reviewed.
- No secrets are committed.
- Changes are logically grouped.
- Conventional Commits is followed.

## Approval

- Tester: APPROVED
- Documenter: COMPLETED
- Committer: COMPLETED
